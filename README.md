# pt-dlss5-runtime

NVIDIA's DLSS 5 neural rendering runtime (`nvngx_dlssnr.dll`), kept here so the
[P.T. PC port](https://github.com/LoreanXavier/pt-pc)'s DLSS 5 installer can fetch it.

The file is NVIDIA's own, unchanged. It is not a P.T. port file and nothing here is code.

| Release | File | Bytes | SHA-256 |
|---|---|---|---|
| `dlssnr-310.9.16` | `nvngx_dlssnr.dll` 310.9.16.0 | 266424944 | `2bc19bc09a7b89dd44f73e2ac0108fcc586e2154bdd0830f242f4f040e28789f` |

The port's installer refuses the file unless its SHA-256 matches the one above.
